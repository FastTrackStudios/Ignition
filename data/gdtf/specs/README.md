# GDTF spec research

Manufacturer datasheet numbers for the venue's cheap fixtures, gathered from manuals, listings and reseller spec tables so GDTF profiles can be generated. One JSON per fixture; guessed values carry a sibling `*_guess: true` key and a reason in `notes`.

The repo's `crates/ignition-viz/src/channel_map.rs` is DMX truth; the datasheets here are for GDTF metadata. Conflicts between the two are recorded in each file's `notes`.

Confidence: **manual found** = DMX chart taken from a manufacturer manual/profile; **listing only** = listing/reseller specs, channel names from the venue console, ranges guessed; **guessed** = product could not be identified, everything beyond the console's channel names is a guess.

## Not found

- LED MINI BEAM WH: no 8ch white-LED mini beam chart exists online; every generic 10W mini beam found is RGBW. Closest is the discontinued Epsilon Pro Mini Beam (no chart retrievable).
- MINI DERBY: no listing/manual matches the console's 9ch map (Mode, R, G, B, Color Control, Strobe, Fade, Motor Speed, Motor Spin); the repo's Purelight FX Mini Derby 2 GDTF is 8ch.
- ENDYSHOW PL-32M: manual exists on manuals.plus but the site blocks fetches; 8ch value breakpoints guessed.
- Czgor 15w2p pinspot: no DMX chart anywhere; a reviewer reports only CH6 responds over DMX.
- Solena Max Par 54 RGB: no manual PDF; weight/beam angle guessed.
- Betopper LB150 / U'King ZQ02341: colour and gobo slot names not published (color1..11).
- Base Hazer 1500: weight not in manual (Pro figure used). No gdtf-share entries found for MBDMX-Plus, Base Hazer 1500 or Hurricane Haze 1DX (site needs login).
- Rockstrip 252 beam angle; ZQ01334 lumens.

## Notable conflicts with the repo channel map

- Betopper 150W: colour wheel is 12 slots in 5-value steps (not 9 in 10s); ch11 is reserved, ch12 is PWM/dimmer-curve/reset — not Focus/Reset as guessed.
- U'King ZQ02341: not DMX-identical to the Betopper despite shared chassis (colour 0-9 white then 7 colours in 10s; ch11 auto/sound macro).
- Mini Gobo TY-30 11ch: attribute order matches; colour slots are 16-value steps in order white, red, pale blue, orange, blue, yellow, green, pink (repo guessed 8-value steps, different order). 9ch mode drops the fine channels.
- Uking Par: the venue's 8ch RGBW par has White at CH5 with strobe/function/speed at CH6-8; the repo's 7ch OFL B262 map is the 36x1W RGB unit with no white.
- Rockstrip 252: manual has 3/4/7/24/28ch, no 5ch mode. 7ch matches the repo.
- All others (MBDMX-Plus, Base Hazer, Hurricane Haze 1ch-only, 36 LED Par Can, ZQ01334, Solena Max Bar 28, Endyshow) match the repo order.
