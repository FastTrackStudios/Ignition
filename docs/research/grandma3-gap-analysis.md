# grandMA3 → Ignition capability gap analysis

**Status**: research, 2026-08-26. Produced by reading the grandMA3 v2.2 help
(≈100 pages, listed below) against `docs/spec/**`, `tools/spec_coverage.py
--uncovered`, and the core/studio code. Goal weighting: **P** portable show,
**G** generated cue lists, **B** busking on 8 faders, **V** visualizer.
Table 1 is the console feature set; Table 2 is what the *recipe model*
cannot yet say; the top-10 is the recommended build order.

## Top 10 to build next

1. **DMX output (sACN + Art-Net)** — **M**. Everything else is invisible until this exists; the receive side and the patch model are already there.
2. **XYZ focus deltas (`FocusDelta`) + `orbit()` in metres** — **S**. The single biggest "same show, any venue" win: shapes drawn in the room, not in pan/tilt.
3. **Per-attribute fade/delay + delay/fade fans on recipes** — **M**. Unlocks wipes without phasers, mover drift vs colour snap, and is a prerequisite for MIB.
4. **Move-in-Black** — **M**. Generated cue lists put movers in the wrong place cold; MIB is the fix a human would otherwise hand-patch into every song.
5. **Assert / Cue-only / Release on cues, plus library-by-name (`Ref<Recipe>`)** — **S+S**. Makes generated lists editable without leaks and stops the clone-by-value drift.
6. **3-axis grid tricks (`tricks.grid.*`) + per-axis phase** — **M**. Bars, walls, two trusses; also the base for canvases.
7. **Accel/Decel + Align curves + Invert per attribute** — **S** each. Cheap, and the difference between "chase" and "designed".
8. **Multiple playbacks with the stack's priority classes + HTP between equals** — **M**. Busking needs a look list and the song list at once; the spec already decided the rules.
9. **Group-master modes, Swap/Kill/Toggle/Black keys, fader pages, MIDI fader input** — **S/S/S/M**. The 8-fader promise on a real surface.
10. **Colour intent (xy/CCT/gel/Q) with per-fixture emitter solve, and preset scope** — **L**. The deepest portability item; the GDTF emitter data is already parsed, the spec is written, and until it lands "Warm" is a different colour on every rig.

Deliberately not on the list: cue parts (subsumed by 3), Worlds/filters, Lua, sessions, agenda, layout view — either low value for the four goals or already answered better by Ignition's role/selection model.
